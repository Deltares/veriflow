# The Rhine Case

A compact, end-to-end example that runs a single integrated verification pipeline
to compare multiple models for the Rhine. Start with the **basics** to learn the
core _veriflow_ workflow, then move on to **interpretation** to make sense of the
resulting verification metrics.

Each notebook page includes a banner to **download** it or **open it in Binder**.
